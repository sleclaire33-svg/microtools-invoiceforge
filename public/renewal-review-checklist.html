PRACTICAL WORKFLOW / CERTPAI

Make a renewal date actionable.

For independent professionals maintaining their own renewal records.

01 / CHECK

Find the authoritative source

Record the issuer, reference and source location. Check the actual renewal requirements with the issuer; a date alone does not prove a credential is current.

02 / CHECK

Separate expiry from review

Keep the expiry date and your earlier review date separate. Set the review early enough for the issuer’s processing time and the work you need to do.

03 / CHECK

Record the next action

Use a concrete action such as “confirm evidence requirements with issuer” or “locate completion record.” Add a source reference so you can check your notes later.

04 / CHECK

Review and back up

When you return to the record, verify it against the source and update the next action. Keep a JSON backup of the workspace. Store original documents separately.
